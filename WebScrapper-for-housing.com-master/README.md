## 🎯 About The Project

This project provides a simple yet effective tool to scrape real estate property data directly from **Housing.com**. Whether you are looking for properties in a specific city or analyzing real estate trends, this script automates the process and exports the results into a clean, structured CSV file.

## ✨ Features

- 🏙️ Scrape properties from any search location (e.g., "Pimpri Chinchwad, Pune")
- 📊 Automatically exports data to a CSV format
- ⚡ Fast and easy to run via Jupyter Notebook or Python script
- 🔧 Highly customizable for different property attributes

## 🚀 Getting Started

Follow these simple steps to start scraping:

### Step 1: Find Your Location
Open [Housing.com](https://housing.com/) and search for your desired location (e.g., "Pimpri Chinchwad, Pune").

### Step 2: Copy the URL
Copy the URL of the search results page from your browser and paste it into the designated variable in the code.

### Step 3: Run the Code
Run the `Web_Scrapper.ipynb` Jupyter Notebook or the python script.

Once the code finishes executing, all the properties listed under that URL will be scraped and saved automatically in a `.csv` file in your directory.
